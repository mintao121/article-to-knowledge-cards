# 制作知识卡片 (Make Knowledge Cards)

## 概述
把一段文章或笔记，提炼成若干张「一张卡片只讲一个知识点」的知识卡片，方便记忆和复习。卡片以 Markdown 输出，每张包含：标题、核心知识、简明解释、例子或自测问题。

## 何时使用
- 用户直接粘贴了一段文章 / 笔记，想提炼要点。
- 用户给出了一个本地 `.md` 或 `.txt` 文件路径，想从中提取知识卡片。
- 用户表达「做成知识卡片」「提取知识点」「帮我记笔记」「总结成卡片」「帮我校验理解了没」。
- 不要在本场景之外强行套用本技能。

## 第一步：识别输入
判断输入属于哪一类，只处理纯文本来源：
1. 用户直接粘贴了文本 → 直接使用该文本。
2. 用户给了一个文件路径（仅限 `.md` / `.txt`）→ 用 Read 工具读取文件内容后使用。
3. 其他情况 → 按下方「不支持项」处理。

所有卡片内容必须能在原文中找到依据，禁止添加原文没有的信息。

## 第二步：不支持项（直接拒绝并说明原因）
遇到以下请求，礼貌说明本技能暂不支持，并给出替代建议，不要尝试自行实现：
- **网页抓取 / URL 抓取**：请用户用浏览器复制正文文本后粘贴进来。
- **PDF**：请用户先把 PDF 内容复制为文本，或导出为 `.md` / `.txt` 再粘贴。
- **Anki**：本技能只产出 Markdown 卡片，不导入、不导出、不同步 Anki。
- **图形界面**：本技能只通过对话输出 Markdown，不提供任何 GUI。

## 第三步：提取知识点
通读全文，找出真正重要的知识，遵循以下原则：
- 抓「结论性 / 概念性 / 方法性」内容，不抓流水细节、不抓与主题无关的例子。
- 一个知识点 = 一张卡片；不要把多个不相关的要点塞进同一张卡。
- 当原文是编号清单 / 要点罗列时，每个条目通常就对应一张卡；不要为「凑成一张」而把多条合并成一张大卡。
- 合并或删除重复表达：同一意思只保留一次，取最清晰的表述。若一条是另一条的「概念 + 具体策略 / 例子」，视为同一个知识点，放在一张卡内，不要把概念和举例拆成两张卡。
- 仅基于原文：任何原文未出现的定义、数据、例子都不要写。不确定的内容直接舍去，绝不停靠「（原文未提及）」来填空。

## 第四步：决定卡片数量
- 默认产出 **5-8 张**。
- 若原文真正重要的独立知识点不足 5 个，按实际数量产出（例如 2-4 张），并在开头注明「原文要点较少，共 N 张」。**不要**为满足数量而编造或把一个点硬拆成多张。
- 若原文要点明显超过 8 个且都重要，可超过 8 张；优先保证「一张一知识点」，不要为压缩而把不同点强行合并。

## 第五步：按模板写出每张卡片
每张卡片包含四个字段，严格如下：

```
### 卡片 N：<标题>
- **核心知识**：<一句话点明这个知识点最关键的内容>
- **简明解释**：<用大白话解释，1-3 句，避免堆术语>
- **例子**：<一个具体例子或类比，帮助理解>（可选，但建议尽量提供）
- **自测问题**：<一个能当场检验是否真懂的问题>（可选，与「例子」二选一必填）
```

字段规则：
- **标题**：简短、点题，最好是一个名词短语或一句结论。
- **核心知识**：必须是能从原文直接得出的结论，不发散、不引申。
- **简明解释**：写给「第一次接触这个概念的人」，不用原文未定义的术语；1-3 句。
- **例子 / 自测问题**：至少提供其一，两者都有更佳。例子要具体、可感知；自测问题要能让人当场验证理解，而非「你记住了吗」这类空泛提问。好的自测问题多用「为什么…」「如果…会怎样」「删掉 X 后还成立吗」「把 A 换成 B 结果如何」这类能暴露误解的问法。

## 第六步：输出
- 用 Markdown 输出，最前面写 `## 知识卡片（共 N 张）`。
- 直接展示在对话中即可。若用户希望保存，可把同样内容写入一个 `.md` 文件（如 `<原名>-cards.md`）并提示路径。
- 不调用任何 GUI，不做网页 / PDF / Anki 操作。

## 质量自检清单（输出前逐项确认）
- [ ] 每张卡片只讲一个知识点？
- [ ] 没有重复卡片（同一意思只出现一次）？
- [ ] 所有内容都能在原文找到依据，无编造？
- [ ] 每张卡至少含「例子」或「自测问题」之一？
- [ ] 卡片数量贴合原文重要度（不足 5 时不硬凑、不拆碎）？

## 输入 / 输出示例

输入（用户粘贴）：
> 复利就是利滚利。你把利息继续投资，下一期的本金就变大了，长期下来差距惊人。巴菲特说复利是世界第八大奇迹。

输出：
```
## 知识卡片（共 2 张）

### 卡片 1：复利 = 利滚利
- **核心知识**：把投资产生的利息再投资，下一期以更大的本金计息，收益会指数级增长。
- **简明解释**：普通计息只算本金的利息；复利连「利息的利息」也算，时间越长雪球越大。
- **例子**：本金 1 万、年化 10%，单利 10 年利息共 1 万；复利 10 年后约 2.59 万。
- **自测问题**：为什么同样利率，复利长期收益比单利高得多？

### 卡片 2：复利需要时间才显威力
- **核心知识**：复利的优势在「长期」才明显，短期几乎看不出差别。
- **简明解释**：雪球效应前期慢、后期快，越早开始、持有越久越受益。
- **自测问题**：如果只持有 1 年，复利和单利差别大吗？为什么长期才重要？
```

## 触发示例（用户可能这样表达）
- 「把这段文章做成知识卡片」
- 「提取这篇笔记的知识点」
- 「读一下 notes.md，帮我生成复习卡片」
- 「总结成 5-8 张卡，每张讲一个点」
